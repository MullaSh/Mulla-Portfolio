Inside the automation framework

A Page Object Model built with Katalon custom keywords. Each layer has one job, so a UI change is fixed in one place.

1Locator

Kept in the Object Repository. One parameterized object finds any row.

//td[normalize-space()='${code}']

2Page action

One keyword per page action, built from small steps. Shared steps come from a common package.

// EmailTempAction.groovy
def addNewEmailTemplate(...) {
  openForm()
  fillBasicInfo(code, name, type, subject)
  fillEmailBody()
  handleActivePeriod(from, to)  // shared
  handleCriteria()              // shared
  saveForm()                    // shared
}

3Test case

Reads like the business steps. No locators, no waits.

openWeb()
login()
goToEmailTemplate()
addNewEmailTemplate(...)
verifyApprovalStatus(code, "New")
